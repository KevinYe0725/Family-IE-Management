# 按需 CI 实施计划

**目标**：核心检查必跑、模块按需、高风险全量，前后端并行；本轮不推送、不部署。

**方案**：`scripts/ci_plan.py` 从最近成功验证的同分支提交（PR 使用合并基点）计算完整差异，输出明确的测试文件清单。前端构建产物独立提供给后端打包，前端测试不再阻塞后端开始。统一检查门禁成功后才允许部署。

**约束**：不删旧测试；不启动本地应用；不改生产数据和发布安全机制；未知路径、比较失败、核心账务/权限/迁移/依赖变化全量；main 推送只检查，部署仍需显式手动输入。

- [x] 先添加选择器回归测试：文档、前端、贷款联动、核心变更、未知路径、强制全量、跨多提交与删除文件。
- [x] 实现标准库 Python 选择器、基线查找、清单校验及运行入口；无匹配测试失败，不能静默通过。
- [x] 修改 workflow：范围判断、前端构建、前端测试、后端测试打包、统一门禁、部署；增加手动全量和每日有变更时全量（不部署）。
- [x] 验证选择器与发布脚本、工作流语法、前端核心用例；记录实际验证范围，不以本地结果声称云端提速。
- [x] 文档说明选测规则、风险联动、跳过原因及维护方式。
