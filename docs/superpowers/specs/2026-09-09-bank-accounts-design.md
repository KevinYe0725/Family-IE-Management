# 银行主账户与币种余额

用户已确认：银行主账户保存名称、银行、可选尾号和家庭归属；每个币种对应现有 financial_accounts 单币种账户。同一卡同币种唯一。主账户不记账、不存重复总余额。旧业务 accountId/fundingAccountId 保留子账户语义。

全站使用统一选卡组件，根据业务币种匹配子账户；缺币种时提供添加入口，不猜余额、不自动换汇、不换另一张卡。未知币种由用户明确选择。现有 CNY/HKD/USD 范围不扩展；贷款、资产、周期账单保持 CNY 限制。支付仍后端验证归属、币种、期初、归档、余额，原有幂等/冲销不改。

账户管理使用弹窗和银行卡分组，创建一次主账户并配置币种余额；各币种明确确认期初。新增币种就地完成后返回原表单。卡片显示原币余额，任何折算不作为可付款余额。主账户编辑共享名称/银行/尾号。归档必须检查子账户余额及活跃绑定，不删除历史。

流水、分页、导出增加 bankAccountId 筛选；不拼接前端分页。主账户 ID 与子账户 ID 严格分离。预算、行情、成本、贷款计算和账本汇总不重构。

现有测试数据可在上线前备份后协调重置，但开发中不删除线上数据，不将清空逻辑放入 Flyway。保留用户/家庭/成员/权限。兼容升级先为每个旧 BANK 账户独立建立主账户，不凭名称合并，不改变余额与流水。
