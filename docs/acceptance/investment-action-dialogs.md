# 投资操作弹窗与信息层级

## 范围

投资模块的记一笔投资、编辑投资记录、新建/编辑投资账户、嵌套新建资金账户、手工价格、投资账务历史改为居中弹窗。定投既有居中弹窗保留并精简重复提示。其他模块的抽屉默认行为不变。

## 布局

- 记账/编辑采用宽弹窗：左侧输入证券、账户、数量、单价、费用和日期；右侧核对现金来源、可用余额、现金合计与预计余额。核心金额更醒目，提交区固定在表单底部。
- 简单编辑采用较窄弹窗，不强制所有表单两列。小屏纵向排列，日期与费用单独占行，主体可滚动。
- 账务历史突出入账/更正/冲回与日期；展开后显示操作人、记录时间、借贷明细。固定业务来源时不再显示无必要的来源筛选；内部账户编码可通过提示查看。
- 日历仍挂载在弹窗内部、滚动主体之外，外层不裁剪浮层。关闭日历不会直接关闭表单。

## 文案与安全信息

删除重复的说明段落和零资金缺口提示；请求ID移到可展开的错误详情。仍保留字段校验、真实现金来源、余额不足、期初不产生现金流、更正冲回重记、历史来源不变等必要说明。参考报价仍明确不等于成交价。

没有改动请求载荷、幂等键、记账计算、权限或后端API。居中组件复用已有未保存保护、保存中禁用、焦点限制、关闭后焦点恢复和嵌套弹窗逻辑。

## 验证

新增测试覆盖未保存关闭保护、嵌套Escape、保存中不可关闭/编辑、请求ID展开、日期浮层以及诊断/历史条目的键盘导航。独立复审发现的原生summary焦点问题已补明确tabIndex并增加回归。

本轮没有启动本地业务HTTP服务。组件测试与构建不等于真实浏览器视觉验收；实际屏幕布局及部署后的效果仍需在上线后核对。
