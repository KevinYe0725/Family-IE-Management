# 收支一致性修复与实机验收

## 范围与口径

- 首页、收支明细和年度收支：共用收支记录的金额与发生日期，贷款现金还款包含本金和利息；买方直接代偿不是家庭现金支出。
- 费用预算：按账本费用计算，还款本金不占费用预算。与收支记录不同的指标明确称为“费用”。
- 资金流水：展示放款、资产与投资买卖、还款、账户互转等实际现金账户变动，保留原币，不把期初余额当作本期收入。
- 金额计算用精确十进制；外币使用入账历史汇率。缺少汇率不得当零。
- 测试仅操作课程项目的模拟账目，不涉及真实银行或证券交易；保留现有用户数据。

## 云端验收清单

以下项目必须记录实际结果，未执行不得标为通过。

- [ ] 首页/收支页/年度：当月、历史月、日图、分类、成员、零数据。
- [ ] 收支：新建收入和支出、编辑金额日期分类账户、详情、删除、筛选、分页、CSV。
- [ ] 账户：银行卡和钱包、币种账户、余额、期初、账户互转、换汇、资金流水及入账轨迹。
- [ ] 预算：总预算、分类与成员预算、预算明细、修订、停用、模板、导出。
- [ ] 周期账单：创建、编辑、确认、跳过、暂停、恢复、提醒与收支联动。
- [ ] 贷款：现金到账、购置资产、计划还款、部分提前还款两策略、结清、余额不足、历史与收支联动。
- [ ] 资产：期初资产、现金购置、估值、编辑、出售/归档、关联贷款、净资产。
- [ ] 投资：证券搜索、行情、买入、卖出、费用、分红、历史、定投确认、账户余额与汇率。
- [ ] 家庭与权限：个人中心、成员显示、初始化引导、提醒、跨家庭隔离自动化检查。
- [ ] 部署：Actions 成功、线上版本匹配、服务健康；修复后再次浏览器回归。
- [ ] 账本：现金非负、按币种借贷平衡、当前余额可重算、还款本息分配一致。
