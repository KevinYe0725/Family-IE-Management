# main：账户互转中的换汇入口

## 使用路径

收支明细 → 账户 → 账户互转 → 换汇互转 → 记录换汇。

- 互转窗口顶部提供“同币种互转”和“换汇互转”，沿用现有分段按钮样式。
- 同币种只显示普通互转；换汇显示换汇记录及操作，不需要往下找另一个模块。
- 换汇继续使用原有的转出/转入币种账户、日度参考汇率、实际到账及手续费表单。
- 银行卡“卡内换汇”直接进入换汇模式并预选该卡的两个币种账户。
- 后端只支持单币种时，不放开换汇按钮；权限和资金校验未绕过。

## 安全边界

不改变汇率计算或账本过账逻辑。未知结果的换汇请求在当前登录会话的查询缓存中禁止自动垃圾回收，切换模式/离开面板后重新进入，仍使用原幂等键和原请求核对。确认完成后清空该待处理内容，退出登录仍由认证层清理缓存。

## 回归覆盖

- 从账户互转进入换汇，再返回同币种。
- 编辑时只展示当前活动弹窗。
- 卡内换汇预选正确的币种子账户。
- 单币种环境不可新增换汇。
- 使用日度参考汇率、手工填写到账、费用和双边余额预览。
- 未知结果在面板卸载和普通缓存回收后仍能以相同请求重试。

## main 部署方式

main push 不会自动部署。明确要求部署时，手动运行：

```bash
gh workflow run deploy-stage2.yml --ref main -f deploy_main=true
```

未勾选 deploy_main 的 main 手动运行仅执行构建；Stage 2 原自动部署策略保留。部署仍执行完整 CI、当前分支最新提交检查、发布包校验和公共版本/健康检查。环境只允许指定分支，不开放任意分支。
