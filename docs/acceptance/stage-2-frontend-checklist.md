- [x] 预算服务器用量、修订历史；周期规则、待确认发生项和幂等确认。

- [x] 投资账户、证券搜索、BUY/SELL/DIVIDEND/FEE、持仓、行情刷新与手工价格。
- [x] 贷款向导、等额本息/等额本金/自定义计划、服务端还款表、确认与提前还款。
