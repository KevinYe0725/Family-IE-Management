# 投资 Dashboard 与行情弹窗

## 页面组织

- 投资首页突出组合市值和累计收益，可隐藏汇总金额；无有效数据时保持未知，不补造数字。
- 主导航为持仓、定投计划、交易；账户和汇率保留在管理菜单，已有深链接仍可访问。
- 持仓支持证券/代码搜索、市场筛选、账户筛选、隐藏已清仓。数量、成本、人民币收益和汇率日期按需展开。
- 缺价/缺历史汇率/缺估值汇率合并在一个提示区域，保留相应补充入口。估值规则说明折叠，不反复占据首页。

## 行情流程

- 首页行情按钮或持仓证券名称打开大尺寸行情弹窗；窄屏使用全屏布局。
- 沪深北、港股、美股查询沿用现有数据来源和权限。报价、日/周/月 K、范围、指标、手工价格管理均保留。
- 切换市场会清空旧市场的证券与账户上下文，不能从港股面板误发起 A 股卖出。
- 普通关闭弹窗不会卸载首页持仓组件，因此保留搜索/筛选/展开状态；页面滚动锁交给既有 Semi Modal。
- 从具体账户的持仓打开行情后，买卖草稿带入该证券及账户。若另选证券，清除旧账户上下文。成交价格保持空白，不自动把参考价当成真实成交价。
- 行情转到交易或手工报价表单时先关闭行情，避免叠加两套模态焦点。

## 范围与验证

没有修改后端 API、账本算法、报价刷新频率、数据库或第三方依赖。配色与字体沿用家账；借鉴 Binance 的资产优先、资产对应操作及按需详情逻辑，而非复制其自动下单行为。

回归包含弹窗关闭保留筛选、重复证券跨账户预选、不自动填价、市场切换隔离、人民币与原币收益方向不同、隐私隐藏、只读权限、余额/持仓校验以及既有定投功能。独立复审发现的跨市场上下文和人民币收益缺失问题已补充回归并修复。

本轮不启动本地业务 HTTP 服务；组件测试不代表浏览器实际视觉验收。线上效果需在正式部署后核对。
