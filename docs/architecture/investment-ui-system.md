# 投资模块的信息与视觉规范

## 用户首先需要知道

1. 投资组合现在值多少、累计收益多少，人民币口径紧邻金额。
2. 估值是否可靠；报价失败、延迟和缺失直接可见，不藏入计算说明。
3. 有什么待确认事项。
4. 查看某只持仓、记录实际成交的入口在哪里。

常态首页保持资产/收益 → 数据状态及待办 → 持仓的顺序。计算依据、历史版本、来源时间等按需展开；不增加无可靠历史数据的收益曲线。

## 共用实现

`investment-ui.tsx` 提供 InvestmentButton、InvestmentActions、InvestmentValuationStatus。
`investment-ui.scss` 定义角色化令牌。Dashboard、定投、行情和证券搜索样式消费共用令牌，不再分别指定近似字号和灰色。

页面使用 investment-ui 作用域；投资弹窗显式使用 investment-dialog，菜单使用 investment-menu。共用页面/弹窗的 className 为可选参数，其他模块默认呈现不变。

## 层级规则

| 角色 | 规范 |
| --- | --- |
| 主操作 | primary：实心主色。首页突出记一笔；定投页突出新建计划；弹窗突出确认/保存 |
| 次操作 | secondary：中性描边，如行情入口、逐期待确认操作 |
| 工具操作 | quiet：低强调，如刷新、更多、展开明细；移动端和键盘均可访问 |
| 危险操作 | danger：明确表达归档、结束等行为，不与普通操作混色 |
| 核心资产 | 36px，窄屏32px；数字等宽、未知仍显示未知 |
| 本次金额 | 28px；不可用小字掩盖真实扣款 |
| 标题 / 分区 | 24px / 18px，字重600 |
| 正文 / 元数据 | 14px / 12px；数据异常说明使用正文级别 |
| 边界 | 控件8px、面板12px、弹窗16px圆角；单行操作40px，触屏44px，双行证券选择48px |

主色用于交互与选中，不用来给所有证券加装饰色。收益保留既有绿正红负且有数值符号；数据异常使用警示色，正常数据不铺绿色成功标签。隐藏金额只隐藏汇总，按钮明确说明范围。

## 入口收敛

- 顶部保留行情、管理、记一笔，移除首页重复的新建定投按钮；定投页保留自己的创建入口。
- 持仓行保留证券查看、明细和更多操作；买卖进入明确菜单，不依赖悬停才出现。
- 定投的稍后提醒/跳过、暂停/结束使用相同菜单；编辑仍有明确入口，账户数据异常时保持禁用。
- 人民币收益、原币收益、报价来源和时间仍可查看。精简不能删除核对依据。

## 验证边界

测试覆盖默认可见的数据异常、菜单选中操作与键盘关闭、菜单后的原资金账户/证券预选、只读与停用证券权限、既有投资记账及定投流程。没有修改后端、数据库、财务计算或新增依赖。

组件测试和构建不是实际浏览器视觉验收；上线后仍需核对屏幕布局、弹层位置、实际文字长度及触屏操作。
